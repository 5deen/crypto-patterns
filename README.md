# Geistgrid

Text-based design using geometric patterns.

A Geistgrid pattern is a two- or three-dimensional grid of various colours and
shapes, each representing a character. The system generates a public grid of
these shapes, and re-entering the phrase verifies each character against the
predefined mapping rules. If the sequence aligns with the original, the pattern
remains unchanged from its initial creation.
